# Requirements — 実機なし先行実装の4段階

## 概要・正本

確定仕様 [20260929-device-independent-implementation.md](../../docs/ideas/20260929-device-independent-implementation.md) を入力に、全 P0 の本体実装と自動検証を先行し、実機受入を後でまとめて行う。計画作成日は 2026-10-01、ディレクトリの日付は入力仕様に合わせる。`$prepare-steering` / 内部 `$steering` の計画成果物は本ディレクトリの3文書だけであり、その計画作成時点では実装・試験・他文書更新を開始しなかった。現在は別途明示された `$implement-steering` に従って実装を進め、進捗はtasklistを正本とする。

要求全文は [PRD](../../docs/product-requirements.md)、撮影・連携の追加条件は各確定仕様を参照する。今回仕様が優先する差分は、独立実装の開始条件、削除後表示、写真権限、ズーム操作である。それ以外の品質・禁止・安全・CF／BI条件を置換しない。[tasklist.md](tasklist.md) の79行が今回の作業と証拠の対応先、[design.md](design.md) が所有・引渡し・検証設計である。

旧撮影 P01〜P21 と旧連携 T01〜T26・T06A・T07A の現在状態・失敗・部分証拠は旧 tasklist に残す。実装開始時の N00 で新タスクの現行進捗正本を本 tasklist に確定し、旧 task は履歴と元の受入義務として参照する。旧タスク全体を完了へ変更したり、同じ作業を2台帳で進めたりしない。

## 背景・利用者

現状は撮影・保存の探索実装と連携の値契約、隔離確認、Range の部分観測までであり、製品の実通信・再生・Photos・削除・撮影補助まで完成した状態ではない。本人は iPhone 18 Pro と Mac mini を使い、開発後半に実機操作をまとめて実施する。開発担当は未実装、探索候補、未接続、実装済み実機未確認を区別しながら先行する。

主なユースケースは、音声付き Log 撮影、状態を区別した一覧と再生、本人が開始した Wi-Fi 転送、同一 Rec.709 軽量映像の明示確認と写真保存、条件を満たす容量整理、単数の不要動画破棄である。

## 4段階とユーザーフロー

| 段階 | 実装範囲・到達点 | 実機受入を残す対象 |
| --- | --- | --- |
| 1 | 共通永続化、原本の保存／内容対応／read lease／復旧、ライブラリ・詳細・履歴の状態、ローカル実再生、単独所有の Composition | D04 の端末保護・実中断、G2B の実撮影原本、実原本再生 |
| 2 | 接続・登録、全媒体制御、原本送信と最終保存先の独立全内容検証、変換・固定版配信・実再生、確認／失効／全必要 ACK／再登録 | G1 の実回線・背景／ロック・負荷、G2B 結合、D02／G3／G5 品質 |
| 3 | Photos の追加／必要時読取・不明照合、実削除／再起動照合、複数整理と単数破棄、一覧／履歴の接続 | 実 Photos 権限・登録境界、許可した試験原本の実機削除・復旧 |
| 4 | 設定と撮影、WB／音声、補正、人物 AF、ND、ズーム／レンズ、標準 Rec.709 表示と統合 | D01／D03 実方式、全能力・品質、端末負荷と全 P0 最終受入 |

段階は主な変更のまとまりである。前段の実機合格や段階全体の完了を、独立後段の開始条件にしない。例えば段階2の隔離サーバーは G2B 待ちでも進め、段階3の Photos／削除は試験実ファイルで進め、段階4の AF／ND は G1 待ちでも進める。タスクの直接依存だけを適用する。

1. 保存設定と対応条件を確認し、REC／STOP、必要時の WB 再固定を行う。音声・実適用・保存結果を別々に表示する。
2. ズームは目標選択→構図予告→移動開始→目標自動停止とし、途中のズーム停止と録画停止を分ける。
3. 一覧から原本／軽量版を1本ずつ再生する。転送・写真保存・容量整理は複数開始でき、結果・未処理は動画別に表示する。
4. Wi-Fi で本人が選んだ原本だけ転送し、保存検証後の同一軽量版を実再生して明示確認する。本人停止・REC／保存・回線条件を重ねて扱う。
5. 写真保存操作に必要な追加権限を求め、結果照合が必要な時だけ理由付きで読み取りを案内する。
6. 有効証拠に基づく手動整理成功は通常一覧へ残す。単数破棄は対象・消失リスクを確認し、実削除成功を照合したものだけ履歴へ移す。
7. 不明結果は管理記録から照合し、原本・外部動画・確認証拠の状態を捏造しない。

## 要件

### R1: 全要求と4軸を保持する（DI-01〜04）

- FR-01〜17、NFR-01〜04 の21要求・79ACを tasklist に個別追跡する。原文の条件は短い行見出しで縮小しない。
- 実装、自動検証、実機確認、PRD受入を独立管理する。コードレビューは自動実行とは別の証拠とする。
- 共通 store、原本管理、共有 Ports、Composition は design の単独所有と引渡し順に従う。T03 契約・P05／P06 成果を複製再実装しない。
- D04／G2A のディスク部分引渡しと、G2B の真の撮影保存事実、G2C の内容対応・全 reader 解放を区別する。fixture の正常は実撮影正常を証明しない。

### R2: 実 I/O を含む本体を実装する（DI-02〜04・08）

- 実装できる disk commit／再open、実ファイル読み書き・削除、再生、隔離通信・保存、Photos、解析・描画・撮影制御をモックだけで代替しない。
- 方式や標準変換資材が不足する部分は当該処理を未実装／保留とする。実機未確認の完成品という表示で未接続を隠さない。
- 保存分類の正常／部分／不明／失敗、録画と表示の分離、原本非改変、独立全内容検証、失効 commit 後 ACK・全必要 ACK 後公開を維持する。
- 全媒体の Wi-Fi 制限、背景／ロック中に OS が許す既開始転送／取得、媒体を含まないモバイル状態同期、個別失敗と共通問題、本人停止／取消・全件停止を維持する。前景だけや全量取得必須へ縮小しない。

### R3: 原本本体・管理記録・一覧を分ける（DI-05）

- 整理は同一原本の保存検証＋同一 Rec.709 映像の有効確認等を動画別・削除直前に再判定する。写真・追加 backup・再接続・再生を条件に追加しない。
- 整理成功後は通常一覧に残し、原本なし、軽量版の取得／再生可否、確認・写真状態を分ける。オフラインで未取得媒体を再生可能と表示しない。
- 破棄は対象・消失リスクへの明示操作を1本ずつ得る。実削除成功後だけ履歴へ移す。履歴は管理記録でありゴミ箱や原本の隠蔽・移動ではない。
- 削除意図・実ファイル・結果 commit を別々に照合する。不明は要確認のまま残し、未実行削除を自動実行しない。Mac mini／写真を連動削除しない。

### R4: 写真追加と結果照合（DI-06）

- 保存時の追加権限と、照合時の読み取り案内を分ける。撮影起動時の一律要求、権限拒否による無関係な撮影停止をしない。
- 登録意図、取得完了、Photos 結果、管理 commit、写真側存在を分ける。拒否・限定・対応不明・読取可でも未発見を未保存と断定しない。
- 連打・再試行・登録直後再起動でも無条件再追加しない。写真側の本人削除を自動復活しない。アルバムや手動再保存の未合意機能は採用しない。

### R5: 撮影・AF・ND・ズーム・表示（DI-07〜08）

- 希望値、能力、実適用、実機評価済みを分ける。WB 安定・ND・人物検出待ちだけで REC を止めない。静寂と音声障害を分け、有限復旧後も自動 REC しない。
- AF は複数露出対象と単一主役、通常合焦・前後追従・同一主役再捕捉・別人へ移行なし・追跡 OFF の人物優先 AF まで含める。2026-10-18のS45本人承認に従い、人物なし時はタップ位置AF、初回意図は本人選択・保存復元・REC非阻害、見失い猶予は変更可能な暫定3秒後に保持/再指定待ちとする。実機品質や他の未合意候補を採用済みにしない。
- ND は解析入力と根拠から方向／理由／両立困難を扱い、遅延・停止・不確かな世代で旧 OK を失効する。常に保留だけでは完成にしない。2026-10-18のS46本人承認に従い、入力映像の観測時点から変更可能な暫定1秒で結果を失効し、交換可能な入力信号別の暫定基準で方向と理由を参考表示する。端末内で完結し、バックエンド通信やND判定をRECの条件にしない。正確なND段数や実機品質の採用はこの合意に含めない。
- ズーム予告で実倍率を変えず、原本へ焼き込まない。目標／途中停止と近傍停止支援を持ち、速度・精度・吸着許容差を版付き暫定設定と実機採用値に分ける。
- 適合する実 Log と由来・版・利用条件の確認済み標準資材だけを Rec.709 変換へ使う。compress-only、タグ変更、独自係数は代用しない。

## 非機能要件・制約

- NFR-01 の起動／次 REC、NFR-02 の保存・写真・削除復旧、NFR-03 の継続・安全、NFR-04 の実データ許可を全て保持する。音声省略や自動原本削除で性能目標を満たさない。
- Swift／SwiftUI／native iOS、既存 `FrameRelay.xcodeproj`、iOS Deployment Target `27.0`、Swift 言語モード `5.0` を維持する。外部依存追加・project生成をしない。
- build/test は実在構成を再確認して実行し、必要な単体・disk・再生・隔離通信・Simulator／UI・レビューを残す。0件・skip・未実行を成功にしない。固定 coverage 閾値を新設しない。
- 私的媒体・秘密・実 DB はリポジトリへ入れない。既存未コミット変更と README を保持する。実データ削除・上書き・本番 DB 移行・デプロイは別の対象別明示許可を維持する。
- 軽微で可逆な配置・内部設定は根拠と暫定性を記録して進める。要求縮小、禁止変更、消失、実機証拠必須の重大方式は該当部分だけ保留し本人へ相談する。各段階の再承認を新設しない。
