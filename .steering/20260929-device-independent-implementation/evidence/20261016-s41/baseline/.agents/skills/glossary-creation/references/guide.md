# 用語集作成ガイド

## 目的

用語集は新しい概念を作る場所ではなく、永続文書で使用する言葉を同じ意味で再利用できるようにする正本である。

## 分類

- ドメイン用語: 利用者、業務、機能、成果物
- UI用語: 画面、操作、表示状態
- データ用語: entity、field、状態値
- 技術用語: framework、library、architecture概念
- 運用用語: PRD、MVP、steering、quality gate

## 記述項目

- 定義: 他の用語へ循環せず説明する
- 本プロジェクトでの使用: どの文脈・文書で使うか
- 関連用語: 上位・下位・対義・依存関係
- 英語表記: コードやUIと対応するときに記載する
- 参照先: 根拠となる永続文書

## 更新条件

- 新しい状態名、画面名、entity名を永続文書へ追加した
- 同じ意味の表記が複数文書で揺れている
- libraryやarchitecture概念を採用・廃止した
- 既存用語の意味または適用範囲が変わった

## 避けること

- 実装・仕様にない概念を補う
- 製品固有の前提を汎用語として固定する
- 古い名前を説明なしに残す
- 用語の定義に同じ用語を使う
